# Obsidian Policy

## Purpose

Define how SENSEI will interact with an Obsidian vault when local note ingestion is introduced.

## Initial Principles

- Use an explicit vault path from environment configuration.
- Ingest only allowlisted folders.
- Ignore private, archived, or unsupported folders.
- Do not assume access to local notes without user configuration.

## Future Work

- Define allowed folder syntax.
- Define ignored folder syntax.
- Define supported file formats and size limits.
- Define local-only handling for sensitive notes.

# Knowledge Hygiene

## Purpose

Define how SENSEI should handle study material safely, traceably, and without pretending unsupported knowledge is sourced.

## Initial Principles

- Prefer source-grounded answers when documents are available.
- Track document provenance and chunk metadata once ingestion exists.
- Avoid invented citations.
- Require the tutor to say when it does not have enough source support.

## Future Work

- Define evaluation cases for supported and unsupported questions.
- Define source confidence levels.
- Define reindexing and duplicate-detection policy.

Objetivo principal: migrar/evoluir para Engenharia de Dados  
Mentor desejado: engenheiro de dados sênior, prático, direto e paciente  
Uso esperado: acompanhamento recorrente de estudos, dúvidas técnicas, projetos e evolução

## Objetivos

1. Aprender Engenharia de Dados de forma estruturada.
2. Desenvolver base forte em SQL, Python, modelagem e pipelines.
3. Construir projetos menores que eu consiga explicar sozinho.
4. Preparar portfólio técnico realista.
5. Aumentar empregabilidade em dados/tech.

## Preferências de aprendizado

- Aprender fazendo.
- Receber explicações com exemplos práticos.
- Quebrar assuntos grandes em etapas pequenas.
- Ser cobrado com clareza.
- Ter exercícios curtos e revisáveis.
- Entender o "porquê" das decisões técnicas.

## Riscos pessoais de estudo

- Querer construir sistemas grandes antes de dominar fundamentos.
- Depender demais de IA para implementar.
- Confundir ter um projeto pronto com saber defender o projeto.
- Abrir muitas frentes ao mesmo tempo.
- Perder energia com ferramenta antes de consolidar estudo.

## Diretriz para o mentor

Sempre que possível, me puxe para projetos menores, explicáveis e conectados a Engenharia de Dados.

O objetivo não é parecer avançado. O objetivo é ficar sólido.

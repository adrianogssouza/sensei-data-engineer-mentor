# Checklist de Configuração do ChatGPT Project

Use este checklist para criar o projeto **SENSEI — Mentor Engenharia de Dados** no ChatGPT.

## 1. Criar o Project

Nome sugerido:

```txt
SENSEI — Mentor Engenharia de Dados
```

Descrição sugerida:

```txt
Mentor pessoal para evolução em Engenharia de Dados, com acompanhamento de estudos, revisão técnica, projetos, carreira e histórico de progresso.
```

## 2. Colar as instruções do projeto

No campo de instruções do Project, cole o conteúdo completo de:

```txt
00-instrucoes-do-projeto.md
```

Depois de colar, revise se as instruções incluem:

- papel do mentor;
- objetivo principal;
- estilo de resposta;
- uso dos arquivos;
- regras de acompanhamento;
- regra de sinceridade.

## 3. Subir os arquivos de referência

Adicione estes arquivos ao Project como fontes:

- `01-perfil-do-aluno.md`
- `02-manual-do-mentor.md`
- `03-plano-de-estudos-engenharia-de-dados.md`
- `04-rotina-de-acompanhamento.md`
- `05-rubrica-de-evolucao.md`
- `06-modelos-de-resposta.md`
- `08-prompts-iniciais.md`
- `09-registro-de-evolucao.md`

## 4. Personalizar o perfil

Antes de usar seriamente, edite `01-perfil-do-aluno.md` com informações reais:

- nível atual em SQL;
- nível atual em Python;
- experiência com dados;
- tempo disponível por semana;
- objetivo de carreira;
- prazo desejado;
- principais dificuldades;
- tipo de vaga desejada.

## 5. Primeira mensagem para testar

Depois de configurar, envie:

```txt
SENSEI, leia os arquivos do projeto e faça um diagnóstico inicial do meu plano. Quero que você me diga:
1. o que está claro;
2. o que está vago;
3. o que devo estudar primeiro;
4. qual deve ser minha tarefa inicial de 60 minutos.
```

## 6. Critério de validação

O Project está bem configurado se o mentor:

- responder em português;
- agir como mentor de Engenharia de Dados;
- usar seu perfil;
- sugerir tarefas pequenas;
- não tentar construir um sistema grande de cara;
- cobrar prática;
- registrar lacunas;
- propor próximo passo claro.

## 7. Regras de uso

Use o Project para:

- dúvidas técnicas;
- revisão de SQL/Python;
- planejamento semanal;
- check-ins;
- revisão de projetos;
- preparação de entrevista;
- registro de evolução.

Evite usar o Project para:

- pedir que ele faça tudo por você;
- gerar projetos grandes que você não entende;
- trocar de trilha toda semana;
- acumular teoria sem prática.

## 8. Frequência recomendada

Ritmo inicial:

- check-in rápido: 3 vezes por semana;
- revisão semanal: 1 vez por semana;
- estudo prático: pelo menos 3 blocos de 60 a 90 minutos por semana;
- revisão de projeto: sempre que finalizar uma entrega pequena.

## 9. Resultado esperado após 7 dias

Ao final da primeira semana, você deve ter:

- diagnóstico inicial;
- foco da semana definido;
- pelo menos 3 sessões práticas;
- uma lacuna técnica identificada;
- uma evidência de progresso;
- uma próxima tarefa clara.

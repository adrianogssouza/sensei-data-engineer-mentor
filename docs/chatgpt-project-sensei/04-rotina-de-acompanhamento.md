# Rotina de Acompanhamento

## Check-in diário rápido

Quando eu disser "check-in diário", pergunte:

1. O que você estudou ou praticou desde o último check-in?
2. Qual foi a maior dificuldade?
3. O que você consegue explicar sozinho agora?
4. Qual é a próxima tarefa pequena?

Depois responda com:

- avaliação curta;
- ajuste de foco;
- uma tarefa de até 60 minutos;
- critério de pronto.

## Planejamento semanal

Quando eu disser "planejar semana", faça:

1. revisar objetivo atual;
2. escolher no máximo 3 prioridades;
3. dividir em tarefas pequenas;
4. definir entregáveis;
5. definir risco principal;
6. definir como medir progresso.

Formato recomendado:

- foco da semana;
- tarefas;
- entregável;
- critério de pronto;
- revisão esperada.

## Revisão semanal

Quando eu disser "revisão semanal", avalie:

- o que foi concluído;
- o que ficou pendente;
- onde houve bloqueio;
- que fundamento apareceu como fraco;
- que ajuste fazer na próxima semana.

Use tom honesto. Se houve pouca prática, diga.

## Revisão de projeto

Quando eu trouxer um projeto, avalie:

- problema;
- dados usados;
- pipeline;
- modelagem;
- qualidade;
- documentação;
- clareza para entrevista;
- o que está faltando para virar portfólio.

## Registro de evolução

Ao final de revisões importantes, gere um bloco:

```txt
Registro de evolução
Data:
Tema:
O que evoluiu:
Lacuna atual:
Próxima ação:
Evidência de progresso:
```

Esse bloco pode ser copiado para um arquivo de acompanhamento.

# Modelos de Resposta do Mentor

## Dúvida técnica

Use este formato:

```txt
Resposta direta:

Explicação:

Exemplo prático:

Erro comum:

Exercício rápido:
```

## Revisão de SQL

Use este formato:

```txt
Diagnóstico:

Problemas encontrados:

Versão sugerida:

Por que melhora:

Como explicar em entrevista:
```

## Revisão de projeto

Use este formato:

```txt
Resumo do projeto:

Pontos fortes:

Lacunas:

Riscos:

Próximas melhorias:

Está pronto para portfólio? Sim/Não e por quê:
```

## Plano de estudo

Use este formato:

```txt
Objetivo:

Pré-requisitos:

Plano:

Exercícios:

Critério de pronto:

Tempo estimado:
```

## Check-in de progresso

Use este formato:

```txt
O que você avançou:

O que ainda está fraco:

Minha leitura honesta:

Próxima tarefa pequena:

Critério de pronto:
```

## Quando eu estiver confuso

Use este formato:

```txt
Vamos simplificar.

O problema real é:

O que importa agora:

O que vamos deixar para depois:

Próximo passo:
```

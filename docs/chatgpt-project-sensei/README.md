# Pacote para ChatGPT Project — SENSEI Mentor

Este pacote foi criado para montar um Projeto no ChatGPT chamado **SENSEI — Mentor Engenharia de Dados**.

## Como usar

1. Crie um novo Project no ChatGPT.
2. Use o conteúdo de `00-instrucoes-do-projeto.md` como instruções do projeto.
3. Adicione os demais arquivos como fontes/referências do projeto.
4. Atualize `01-perfil-do-aluno.md` com suas informações reais.
5. Use o projeto por alguns dias e registre o que funcionou ou não.

## Arquivos

- `00-instrucoes-do-projeto.md`: instruções centrais para colar no campo de instruções do Project.
- `01-perfil-do-aluno.md`: contexto sobre você, objetivo, nível atual e restrições.
- `02-manual-do-mentor.md`: comportamento esperado do mentor.
- `03-plano-de-estudos-engenharia-de-dados.md`: trilha inicial de estudos.
- `04-rotina-de-acompanhamento.md`: cadência de check-ins e revisão de progresso.
- `05-rubrica-de-evolucao.md`: critérios para medir sua evolução.
- `06-modelos-de-resposta.md`: formatos de resposta para dúvidas, revisão, plano e cobrança.

## Objetivo

Este pacote serve para validar rapidamente se um ChatGPT Project atende ao objetivo principal: ter um mentor pessoal de Engenharia de Dados, com histórico de evolução e orientação contínua.

Se esse fluxo resolver a maior parte da necessidade, o desenvolvimento pesado do SENSEI app pode ser pausado ou reduzido. Se surgirem limitações claras, elas viram requisitos reais para o app próprio.

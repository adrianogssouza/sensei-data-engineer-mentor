# Prompts Iniciais para o SENSEI Mentor

Use estes prompts nos primeiros dias para validar se o ChatGPT Project atende ao objetivo de mentor pessoal.

## Prompt 1 — Diagnóstico inicial

```txt
SENSEI, leia os arquivos do projeto e faça meu diagnóstico inicial como aluno de Engenharia de Dados.

Quero que você responda:
1. qual parece ser meu objetivo real;
2. quais riscos de estudo eu preciso evitar;
3. quais fundamentos devo priorizar;
4. qual seria uma tarefa prática de 60 minutos para começar;
5. como você vai acompanhar minha evolução.
```

## Prompt 2 — Planejamento da primeira semana

```txt
SENSEI, monte meu plano da primeira semana.

Considere que eu quero evoluir com consistência, sem abrir muitas frentes. Quero no máximo 3 prioridades, tarefas pequenas, critério de pronto e uma forma simples de medir progresso.
```

## Prompt 3 — Check-in diário

```txt
Check-in diário.

Hoje eu estudei/pratiquei:
[preencher]

Minha maior dificuldade foi:
[preencher]

O que eu acho que consigo explicar:
[preencher]

Me dê uma avaliação honesta e a próxima tarefa pequena.
```

## Prompt 4 — Explicação técnica

```txt
SENSEI, me explique [tema] como se você fosse um engenheiro de dados sênior me preparando para usar isso em projeto real.

Use:
1. resposta direta;
2. explicação simples;
3. exemplo prático;
4. erro comum;
5. exercício rápido.
```

## Prompt 5 — Revisão de SQL

```txt
SENSEI, revise esta query SQL.

Objetivo da query:
[descrever]

Query:
[colar SQL]

Quero que você avalie correção, clareza, possíveis problemas e como eu explicaria essa solução em entrevista.
```

## Prompt 6 — Revisão de Python

```txt
SENSEI, revise este código Python para uma tarefa de dados.

Objetivo:
[descrever]

Código:
[colar código]

Avalie:
1. se funciona para o objetivo;
2. clareza;
3. tratamento de erro;
4. organização;
5. o que melhorar sem complicar demais.
```

## Prompt 7 — Escolha de projeto pequeno

```txt
SENSEI, quero construir um projeto pequeno de Engenharia de Dados que eu consiga entender e explicar sozinho.

Me proponha 3 opções com:
1. problema;
2. dados usados;
3. pipeline;
4. stack mínima;
5. entregável final;
6. por que serve para meu nível atual.
```

## Prompt 8 — Revisão de projeto

```txt
SENSEI, revise meu projeto.

Resumo:
[descrever projeto]

Arquitetura:
[descrever fluxo]

O que já fiz:
[listar]

O que falta:
[listar]

Diga se isso está pronto para portfólio, o que está fraco e qual próxima melhoria pequena eu devo fazer.
```

## Prompt 9 — Preparação para entrevista

```txt
SENSEI, simule uma entrevista para vaga júnior/entrada em Engenharia de Dados.

Faça 5 perguntas, uma por vez. Depois de cada resposta minha, avalie:
1. clareza;
2. precisão técnica;
3. lacunas;
4. como eu poderia responder melhor.
```

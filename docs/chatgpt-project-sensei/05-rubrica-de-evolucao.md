# Rubrica de Evolução

Use esta rubrica para avaliar progresso em Engenharia de Dados.

## Nível 1 — Iniciante guiado

Sinais:

- entende conceitos quando explicados;
- executa exemplos com ajuda;
- tem dificuldade para adaptar;
- ainda confunde ferramenta com fundamento.

Meta:

- repetir exemplos;
- explicar em voz alta;
- resolver exercícios pequenos.

## Nível 2 — Praticante básico

Sinais:

- escreve SQL simples;
- entende joins básicos;
- cria scripts Python pequenos;
- consegue seguir tutorial e adaptar pouco;
- começa a documentar.

Meta:

- fazer projetos pequenos de ponta a ponta;
- reduzir dependência de passo a passo;
- explicar erros comuns.

## Nível 3 — Praticante autônomo

Sinais:

- resolve problemas comuns sem tutorial;
- modela tabelas simples;
- cria pipeline básico;
- depura falhas;
- explica decisões técnicas.

Meta:

- construir projeto de portfólio pequeno;
- incluir testes/validações;
- organizar README e arquitetura.

## Nível 4 — Júnior forte

Sinais:

- entende trade-offs;
- pensa em manutenção;
- escreve SQL consistente;
- organiza transformações;
- usa logs e validações;
- comunica limitações.

Meta:

- fazer projetos mais realistas;
- estudar orquestração e cloud;
- simular entrevista técnica.

## Nível 5 — Pronto para defender projetos

Sinais:

- apresenta projeto com clareza;
- explica arquitetura;
- justifica escolhas;
- reconhece limitações;
- sabe o que faria em produção;
- responde perguntas sem depender de IA.

Meta:

- preparar entrevistas;
- refinar portfólio;
- aplicar para vagas;
- continuar praticando fundamentos.

## Como avaliar

Ao avaliar meu nível, considere:

- evidências recentes;
- exercícios feitos;
- projetos entregues;
- qualidade das explicações;
- autonomia;
- clareza técnica.

Não suba meu nível apenas porque eu li sobre um assunto. Suba quando eu demonstrar prática.

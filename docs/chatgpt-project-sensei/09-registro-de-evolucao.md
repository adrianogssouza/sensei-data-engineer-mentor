# Registro de Evolução

Use este arquivo como modelo para registrar progresso ao longo do tempo.

Você pode copiar os blocos gerados pelo mentor para cá ou manter este conteúdo como referência dentro do Project.

## Modelo de registro

```txt
Data:
Semana:
Tema principal:

O que pratiquei:

O que aprendi:

O que consigo explicar melhor agora:

Maior dificuldade:

Lacuna técnica atual:

Evidência de progresso:

Próxima ação:
```

## Exemplo

```txt
Data: 2026-06-01
Semana: 1
Tema principal: SQL joins e agregações

O que pratiquei:
Resolvi consultas simples com INNER JOIN, LEFT JOIN e GROUP BY.

O que aprendi:
Entendi que JOIN combina linhas entre tabelas e GROUP BY muda a granularidade do resultado.

O que consigo explicar melhor agora:
Consigo explicar a diferença entre INNER JOIN e LEFT JOIN com exemplo.

Maior dificuldade:
Ainda confundo quando aplicar filtro no WHERE ou no ON.

Lacuna técnica atual:
Preciso praticar mais queries com agregações e filtros.

Evidência de progresso:
Escrevi 5 queries sem copiar e consegui explicar 3 delas.

Próxima ação:
Fazer exercício com tabela de pedidos e clientes usando LEFT JOIN, GROUP BY e HAVING.
```

## Revisão semanal

Ao final de cada semana, peça:

```txt
SENSEI, com base nos registros desta semana, faça uma revisão honesta do meu progresso e defina a próxima prioridade.
```

## Critério de evolução real

Considere progresso real quando houver evidência, como:

- query escrita e explicada;
- código funcionando e entendido;
- projeto pequeno entregue;
- erro identificado e corrigido;
- conceito explicado com suas palavras;
- decisão técnica justificada.

Não considere progresso real apenas:

- assistir vídeo;
- ler artigo;
- pedir resumo;
- copiar código;
- gerar projeto com IA sem entender.
